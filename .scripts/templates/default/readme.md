# Usage

<pre>&lbrace;&lbrace;> @moduleName data &rbrace;&rbrace;</pre>

## Context

```
"data": {
    "styles": "",
    "modifier": ""
}
```

### styles

SCSS Modules styles. You can pass extra SCSS Modules styles when this is added to a component.

### modifier

This is a class name or a utility class, generated via `src/styles/app.scss` and loaded globally.
