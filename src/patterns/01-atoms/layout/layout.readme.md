## 12 Column Layout

Flexible 12 column layout thats loaded globally. Styles can be found here: `src/styles/layout/row.scss`.

Layout variables can be found here: `src/styles/settings/variables.scss`

```
layout: (
    max-width: 1024px,
    gutter: 20px,
    browser-context: 16px,
    spacing: 16px
)
```

## Max-width

This is the rows max width before it's centered.

## Gutter

This is the padding left and right of the column.

## Breakpoint Sizes

- `sml`
- `med`
- `lrg`
- `xlrg`
- `xxlrg`

## Row Utility Classes

For breakpoints prefix the size before the utility i.e. `is-{size}-utility-name`.

- `is-justify-left`
- `is-justify-center`
- `is-justify-right`
- `is-align-top`
- `is-align-middle`
- `is-align-bottom`
- `is-reverse`
- `is-relative`
- `no-overflow`
